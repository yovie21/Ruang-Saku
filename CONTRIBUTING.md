# 🤝 Kontribusi

Terima kasih atas minat Anda untuk berkontribusi pada **Ruang Saku**! 🎉

## 🚀 Memulai

1. **Fork** repository ini
2. **Clone** fork Anda secara lokal
   ```bash
   git clone https://github.com/YOUR_USERNAME/Ruang-Saku.git
   cd Ruang-Saku
   ```
3. Install dependencies dan jalankan
   ```bash
   npm install
   npm run dev
   ```
4. Buat **branch** baru untuk fitur Anda
   ```bash
   git checkout -b feat/awesome-feature
   ```
5. Commit perubahan Anda
   ```bash
   git commit -m "feat: tambahkan awesome feature"
   ```
6. Push ke branch Anda
   ```bash
   git push origin feat/awesome-feature
   ```
7. Buka **Pull Request**

## 📏 Standar Code

- Gunakan **TypeScript** untuk semua kode baru
- Ikuti konvensi linting yang sudah ada (`npm run lint`)
- Pastikan `npm run build` berhasil sebelum PR
- Gunakan **conventional commits** (feat:, fix:, docs:, style:, refactor:, test:, chore:)
- Jangan commit environment variables (.env, .env.local)

## 🐛 Melaporkan Bug

Gunakan [Issue Template Bug Report](https://github.com/yovie21/Ruang-Saku/issues/new?template=bug_report.yml).
Sertakan:
- Langkah reproduksi
- Perilaku yang diharapkan vs aktual
- Screenshot jika relevan
- Environment informasi

## 💡 Mengajukan Fitur

Gunakan [Issue Template Feature Request](https://github.com/yovie21/Ruang-Saku/issues/new?template=feature_request.yml).
Jelaskan:
- Mengapa fitur ini dibutuhkan
- Deskripsi detail fitur
- Alternatif yang dipertimbangkan

## 📋 Guideline

- Jangan push ke branch `main` langsung
- Tulis deskripsi PR yang jelas
- Sertakan screenshot untuk perubahan UI
- Test di `localhost:3000` sebelum PR
- Hormati code review process
